# 쿠키런: 크럼블 공략 가이드

쿠키런: 크럼블(Cookie Run: Crumble)의 공개된 정보를 바탕으로 만든 쿠키 도감 · 시너지 조합 계산기 · 스테이지/보스 공략 웹사이트입니다.

## 기능
- **쿠키 도감**: 전체 쿠키의 등급, 스킬, 주는/받는 시너지 정보
- **시너지 조합 계산기**: 선택한 쿠키들의 시너지 조합을 계산하고 추천 조합 제공
- **티어 리스트**: 현재 메타 기준 쿠키 티어
- **스테이지/보스 공략**: 초반 벽 구간 및 보스 공략 팁

## 실행 방법
`index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 출처
나무위키, CrumbleHub, CrumbleHelper 등 공개된 커뮤니티 공략 정보를 참고해 정리했습니다.
